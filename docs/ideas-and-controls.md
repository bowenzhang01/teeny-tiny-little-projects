## 1. 武器切换逻辑与操作逻辑优化（用户提议 + 我的展开）

### 1.1 现状与痛点

- B 的三套背挂用硬编码键位：`1` 收回全部 / `2` 轨道炮 / `3` 六管；
  A 的机器人用 `Q` 放下收起 / `F` 自动↔手动 / `1`、`2` 切机器人武器。
- 键位绑定**分散在各个武器组件里**（`useEffect` 各自监听 keydown），
  以后 C/D/E 加进来很容易撞键，而且 HUD 提示、模式切换、视角恢复都要各自维护。
- "当前主武器"概念不统一：B 是"榴弹 ↔ 背挂"的手动互斥；A 是"单主武器 + 手雷 + 机器人"；
  未来 C/D/E 可能有多把主武器要切换。
- 遥控机器人时 A 本体武器只是"隐藏"，但键盘仍然监听（投雷/T 切雷等在遥控时仍可能触发），
  需要**输入上下文隔离**。

### 1.2 目标设计（方向，未实现）

1. **每个角色一张键位表（input profile）**
   - 在 `CharacterConfig` 或独立 `inputMap.ts` 里声明：
     `activeWeaponKeys`、`utilityKeys`、`droneKeys`、`hudHintLines`。
   - 组件只负责"做什么"，不负责"哪个键"——键由角色配置映射到"动作 id"（如 `FIRE`、`RELOAD`、`DEPLOY_BACK_WEAPON`）。
2. **统一武器槽位抽象**
   - 概念：`PRIMARY / SECONDARY / UTILITY 1..N / MOUNTED（背挂/机器人）`。
   - 每角色配置 `slots`，HUD 右侧武器面板直接由 slots 渲染（B 和 A 都能复用）。
   - 切换武器走同一个状态机：`held → switching → held`，切换动画期间锁定开火输入。
   - `Tab` 或 `1/2/3` 在主武器间循环；背挂/机器人继续保持专用键（`2/3`、`Q`、`F`）。
3. **输入上下文（input context）**
   - 上下文枚举：`ROLE_HUD`（A 本体 / B 本体）、`DRONE_REMOTE`、未来 `DRONE_PIP`、角色切换过渡。
   - 每个 `keydown` 先看当前上下文，再查键表；上下文切换时**清空所有按下中的键**（防 WASD/Space 卡住）。
4. **HUD 操作提示统一生成**
   - 做一个 `ControlHints` 通用组件：从键表生成当前上下文提示条（现在 B/A/Drone 各写死一份）。
   - 提示跟随模式变化：B 显示 `1/2/3 · Q`，A 显示 `Q/F/G/T/R`，遥控显示 `WASD/Space/1/2/F/Q`。
5. **收起/切换动画的"忙碌状态"**
   - `weaponBusyUntil`：部署、收起、换弹、遥控模式切换期间，开枪/投雷输入统一忽略（现在靠各组件自己判断，容易漏）。

### 1.3 具体待办（第一批建议）

- [ ] 抽出 `inputMap.ts`：动作 id → 键位；角色配置声明 `actions`。
- [ ] `CharacterRig` / `Hud` 增加统一按键分发，替换各武器组件里的散装 `keydown`。
- [ ] `ControlHints` 通用组件替换 B、A、Drone 三处写死的操作提示。
- [ ] B 的"当前槽位"高亮（榴弹 / 轨道炮 / 六管 / 双挂载），左键语义按槽位解释。
- [ ] A 遥控时彻底隔离本体输入（G/T/R 在 `DRONE_REMOTE` 上下文下不响应）。

## 2. 操作逻辑 Bug 的修正（用户提议）

### 2.1 已知/疑似问题清单

- [ ] **离开遥控后指针锁定状态可能不同步**：
  `document.pointerLockElement` 与 `rangeStore.locked` 可能不一致；
  需要统一"进入/退出遥控"时的一次性锁定同步，并在 HUD 显示 `CLICK TO RELOCK`。
- [ ] **模式切换瞬间按键卡键**：
  `F` 切换时若 WASD/Space 正处于按下状态，切上下文后 `keyup` 可能丢失（窗口失焦 / 快速切换）；
  在上下文切换、窗口 `blur`、pointer lock 丢失时都清空 `keys` 集合。
- [ ] **遥控中突然换人**：
  如果遥控状态下通过小队卡片切到 B，`QuadDrone` 卸载时已做相机还原，但需要确保
  `PointerLockControls` 重新挂载时状态与 HUD 一致（现在部分依赖卸载 cleanup，需要补测试）。
- [ ] **机器人遥控时右键/中键行为**：
  `contextmenu` 已屏蔽，但右键在遥控上下文下无功能也无提示；考虑给遥控定义右键（如传感器切换）。
- [ ] **投雷/换弹在遥控后残留**：
  `G/R/T` 在 `DRONE_REMOTE` 下应完全禁用；当前 GrenadeKit 已加 remote 守卫，需要同样给
  `AssaultLmg` 的 `R`、LaserCiws 的标记逻辑做输入上下文校验（已有部分实现，需走查）。
- [ ] **机器人武器切换与冷却 UI**：
  `1/2` 切武器后若在 MG 上按左键无效（如冷却/空仓）需要明确"dry"反馈；
  DroneHud 的 `MSL CD` 与 DronePanel 的冷却显示要同源（当前各自读 `droneStore`，已一致，但后续重构注意）。
- [ ] **操作提示与真实键位漂移**：
  HUD 写死的 `Q/F/1/2` 与 inputMap 可能不同步；改为键表驱动后自动消除。
- [ ] **窗口失焦/最小化后恢复**：
  清空按键、暂停机器人自动射击（或至少停止视觉/音效）、恢复后再继续。

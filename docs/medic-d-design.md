# D 医疗兵 · MEND-04 完整设计（已确认方向，第一版已实现）

> 本文档记录 D 医疗兵的完整设定与实施思路，**第一版已按其实现**，
> 对应代码：`src/state/medicStore.ts`、`src/weapons/MedicSmg.tsx`、
> `src/weapons/DartGun.tsx`、`src/weapons/SmokeKit.tsx`、
> `src/weapons/SupportDrones.tsx`、`src/hud/layouts/DHud.tsx`。
> 依据用户设定的核心原则：
> - 每个角色的“武器 + 技能”合计**只有四个系统**；
> - 医疗兵定位偏向**辅助/支援**：建模相对简单，HUD 相对复杂；
> - 现阶段角色移动与“全员同场”都未实现，涉及“飞向队友/队友隐形”的内容

## 1. 总览：D 的四个系统

| # | 系统 | 定位 | 输入 |
|---|------|------|------|
| 1 | 轻型冲锋枪（SMG） | 主武器 · 低伤高射速 | 左键连射，`R` 换弹 |
| 2 | 镇定剂针枪（Tranq Dart） | 副武器 · 单发控制 | `2` 切换，右键/左键单发 |
| 3 | 烟雾弹（Smoke） | 投掷物 · 视觉遮蔽 | `G` 投掷 |
| 4 | 四台支援无人机（D1–D4） | 多用途支援系统 | `Q` 展开/收回，`F` 环绕↔支援，`T` 切换支援模式 |

> 无人机**只占一个系统槽位**，内部包含三种可现场切换的支援模式。

## 2. 主武器：轻型冲锋枪（SMG）

- **定位**：医疗兵的常规火力，轻、快、稳，伤害低。
- **射击**：左键按住连射；建议约 **0.08s/发**（初始值，可调）。
- **弹匣**：**40 发**，`R` 换弹，换弹约 1.2s（可调）。
- **命中**：每发 +1 分，命中标靶会推倒（与现有六管/LMG 同一套逻辑）。
- **模型要求**：比 A 的 LMG 简单——紧凑枪身、短枪管、下挂式握把、
  枪身绿色能量线与小型医疗十字标识即可。
- **弹道特效**：**绿色高速曳光**（区别于 A 的红、B 的橙、C 的琥珀），
  命中为小型绿色爆点。
- **与无人机联动**：
  - `ENHANCE` 模式生效时：SMG 散布更低、后坐更小、换弹更快（具体数值后续可调）；
  - 这是无人机的“身体强化”在实机上的体现之一。

## 3. 副武器：镇定剂针枪（Tranq Dart）

- **定位**：非致命控制武器，摸在“医疗辅助”设定上。
- **切换**：`1` = SMG，`2` = 镇定剂针枪；切换后左键即当前武器开火。
- **射击**：单发，约 **0.65s/发**；命中 **+4**。
- **弹药**：**6 发**，打空后约 **1.8s** 自动装填（不占 `R`，R 只服务当前武器的常规换弹；
  若当前武器为针枪，`R` 也可手动触发装填）。
- **命中效果**：绿色细弹道 + 轻微药雾；命中后标靶被“镇定”倒下。
- **模型**：小尺寸注射/麻醉枪：握把 + 细针管 + 透明药囊 + 绿色发光针头。

## 4. 投掷物：烟雾弹（Smoke）

- **投掷**：`G` 向左前方投出（抛物线，复用现有榴弹运动模型）。
- **库存**：**3 颗**，放置后约 **6s** 自动补满（与 C 部署包同风格）。
- **效果**：
  - 落地后形成约 **6s** 的烟雾云（灰绿色半透明球体群，缓慢扩散/漂移/淡出）；
  - **不造成伤害、不推倒标靶**；
  - 纯视觉遮蔽，且作为**无人机协同点**存在：烟雾中/烟雾后仍可由无人机传感器
    稳定标记目标（HUD 文案保留“SCAN THROUGH SMOKE”语义）。
- **模型**：手持小烟幕弹（圆柱体 + 绿色警示环），肉眼可见即可。

## 5. 四台支援无人机（D1–D4）

### 5.1 状态机

```
STOWED（背挂/收纳） ──Q──▶ HOVER（自身周围环绕）
HOVER ──F──▶ ASSIST（飞向队友/全息支援点）
ASSIST ──F──▶ HOVER
HOVER / ASSIST ──Q──▶ STOWED
```

- `Q`：展开/收回。
- `F`：`HOVER` ↔ `ASSIST`。
- `T`：现场切换**支援模式**：`HEAL → ENHANCE → CLOAK` 循环（不依赖 Q/F）。

### 5.2 三种支援模式（现场切换）

| 模式 | 效果（计划） | 当前版本落法 |
|------|--------------|--------------|
| **HEAL · 治疗** | 治疗自身与队友生命，并显示治疗链路 | 无 HP 系统：做成 HUD 治疗链路 + 队友全息标记上的“治疗波”占位特效；未来接真实生命值 |
| **ENHANCE · 强化** | 身体强化：提高机动力/稳定性/换弹速度 | **做实**：环绕期间 SMG 散布更低、后坐更小、换弹更快；HUD 显示 `ENHANCE` |
| **CLOAK · 投影隐形** | 无人机通过投影使**自身与所有队友**暂时隐形 | 占位实现：自身+虚拟队友全息位置出现隐形泡/折射扰动波纹；HUD 显示 `CLOAK ACTIVE · A/B/C/E`；未来挂到真实角色模型 |

- **隐形规则**：`CLOAK` 模式下**自身与所有队友都算**（用户已确认）。
- **“飞向队友”占位**：现状没有角色移动/全员同场，因此
  `ASSIST` 模式的目标点是**虚拟队友全息标记点**（A/B/C/E，颜色区分），
  无人机围绕这些点盘旋并在这些点上投送治疗波/隐形泡；
  未来只需把“目标点来源”从虚拟点位替换成真实队友位置。

### 5.3 无人机细节

- **数量**：4 台（D1–D4）。
- **外观**：小型四旋翼：机身小方块 + 四臂 + 旋翼盘 + 绿色状态灯；
  `STOWED` 时仅 HUD 显示（第一人称看不到背后）；
  `HOVER` 时在玩家周围空域环绕（画面边缘/世界中可见）；
  `ASSIST` 时飞往虚拟队友标记点。
- **传感器**：系统自动标记最近活目标，写入 `medicStore`，
  `LockSystem` 对该目标放宽锁定阈值（复用 CIWS 的辅助锁定思路）。
- **建议数值（可调）**：
  - 展开/收回约 0.4s 过渡；
  - 环绕半径约 1.1m，高度约玩家头顶附近；
  - 支援模式冷却/耗能：建议每个模式有独立能量槽或“支持充能”（具体等定稿）；
  - 全部模式自动运行，**不做**全屏遥控（与 A 机器人不同，D 无人机是纯支援 AI）。

## 6. HUD 设计（D 全队最复杂）

### 6.1 设计原则

- 绿色医疗终端风格（`#4ade80` 主色系），圆角/十字医疗标识为主，
  与 B 青蓝玻璃板、A 红锐角、C 琥珀工业风明确区分。
- 建模简单 → HUD 复杂：除普通内容外，必须展示：
  1. **所有队友（A/B/C/E + D 自身）的医疗状态与其他状态**；
  2. **无人机矩阵**（D1–D4 节点：STOW / HOVER / ASSIST + 支援模式）；
  3. **支援模式状态**（HEAL / ENHANCE / CLOAK 当前项 + 各队友受影响状态）；
  4. 武器状态（SMG / DART / SMOKE）与常规战术信息。

### 6.2 布局草案

- **顶栏**：`D // MEND-04` 品牌 + 罗盘 + NV / NET 状态。
- **左侧**：
  - 自身生命体征（`BioPanel`，D 更突出 ECG/心率）；
  - 外骨骼状态（`ExoPanel`）；
  - **队友三查面板（SQUAD TRIAGE）**：A/B/C/E 每行显示
    心率/血氧/状态（NOMINAL / WOUNDED / CRITICAL）、链路、当前战斗状态，
    以及“是否处于 CLOAK / HEAL 链路”标记。
- **右侧**：
  - **武器面板**：当前武器（SMG / DART）、弹匣、针枪弹药/冷却、烟雾库存与补充倒计时；
  - **无人机矩阵**：D1–D4 节点，每个节点显示 状态（STOW/HOVER/ASSIST）、
    支援模式、链路/能量；下方 `T TRC MODE` 与 `F MOVE` 提示；
  - **战术雷达 + 目标列表**（复用 `Radar` / `EnemyMarkers` / `TargetList`）。
- **中底部 / 底部**：
  - 中央准星 + 锁定环 + `SUPPORT: HEAL/ENHANCE/CLOAK` 当前模式状态；
  - 小队通信（`CommsPanel`）+ 状态胶囊（`LIVE / DRONE / ENHANCE / CLOAK` 等）；
  - 装饰滚动条（复用 `DecoStrip`）。
- **操作提示**：统一 `ControlHints`，内容来自 `inputMap` 的 `roleD`：
  `LMB FIRE · 1/2 SMG/DART · R RELOAD · G SMOKE · T MODE · Q DRONES · F ASSIST · N NV`。

### 6.3 HUD 状态来源

- 自身：`useRange` + `useMedic`。
- 队友：当前为**占位/模拟数据**（与现有 `CommsPanel` 一致的风格），
  后续接“全员同场 + 真实生命值”时替换为真实状态。
- 无人机：`medicStore.drones`。
